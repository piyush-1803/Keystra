## 2025-02-12 - Dashboard Component React.memo Optimization
**Learning:** In a high-frequency update environment (like a dashboard receiving multiple live metric updates per second), the parent component passing changing props (`liveStats`) forces the child component (`Dashboard`) to re-render constantly. While `useMemo` is used inside `Dashboard` for derived state based on `stats`, the component itself is not memoized, causing React to still execute the render function and perform reconciliation on the entire DOM tree of the dashboard, which is very heavy. But wait, `Dashboard` receives `liveStats` which changes every time! If we wrap `Dashboard` in `React.memo`, it will still re-render because `liveStats` is changing! So wrapping `Dashboard` in `React.memo` won't help. We must instead extract the static parts of `Dashboard` into a sub-component that ONLY receives `stats` and is wrapped in `React.memo`.
**Action:** Extract heavy, static UI into a separate sub-component wrapped in `React.memo()` to prevent unnecessary re-renders when a parent component is hit with high-frequency prop updates.
